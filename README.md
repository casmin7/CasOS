# CasOS
A responsive, desktop-inspired webOS ecosystem built completely with native HTML5, CSS3, and Vanilla JavaScript.

![hacktime](https://hackatime.hackclub.com/api/v1/badge/U0ADP8GUBGR/casmin7/CasOS)
[![Website casos.casmin.eu](https://img.shields.io/website-up-down-green-red/http/shields.io.svg)](https://casos.casmin.eu)
---

### CasOS bridges the gap between web layout styling and local desktop system mechanics. Inside, you'll find:
  - Dynamic Window Management: Fully customized draggable application wrappers.
  - Intelligent Z-Index Depth Sync: Active window monitoring that automatically elevates whichever app you click straight to the foreground layer.
  - GNOME-Inspired Control Panels: Translucent dropdown status hubs for system parameters, scheduling calendars, and live active notifications.
  - Snappy System Animations: Custom easing matrices (cubic-bezier) that drive physical scale and opacity pop-up mechanics for a premium UI feel.
  - Built-in Utility Apps:
      - Info Hub: An elegant profile layout showcasing user bios and interactive social endpoints.
      - Android-Style Calculator: A highly responsive grid interface managing complex multi-operation sequential math calculations.
  - More to come

### To try just visit: https://casos.casmin.eu
