# CasOS
A simple begginer made webOS made just with HTML, CSS, JS.

![hacktime](https://hackatime.hackclub.com/api/v1/badge/U0ADP8GUBGR/casmin7/CasOS)


Features:
  - Panels similar to GNOME
  - draggable windows with auto z-index
  - Apps (Info app, calculator, weather, etc.)

To try just visit: ~https://casos.casmin.eu~
